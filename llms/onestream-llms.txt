# OneStream

> OneStream is an enterprise finance platform that unifies financial and operational data into a single source of truth — spanning financial close and consolidation, planning, budgeting, forecasting (FP&A), and reporting — with AI and machine learning applied to automate core finance tasks. Its OneStream Web (REST) API exposes Data Automation functions (Authentication, Data Management, and Data Provider) as a client-agnostic JSON-over-HTTPS service.

This llms.txt was generated by the API Evangelist enrichment pipeline from apis.yml and repository artifacts.

## API

- [OneStream Web (REST) API — Overview](https://documentation.onestream.com/docs/Content/REST%20API/REST%20API%20Overview.html): RESTful JSON service exposing Authentication, Data Management, and Data Provider endpoints; base path /OneStreamApi/api, versioned via ?api-version=; bearer-token auth.
- [Web API Endpoints](https://documentation.onestream.com/docs/Content/REST%20API/OneStream%20WebAPI%20Endpoints.html): Documented operations (ExecuteSequence, ExecuteStep, GetAdoDataSetForAdapter/CubeViewCommand/SqlCommand/MethodCommand, LogonAndReturnCookie).
